# Self Supervised Learning

This lecture introduces autoencoders and self-supervised learning in deep learning. It explains how autoencoders learn compressed representations of data through encoding and reconstruction, with applications in dimensionality reduction, anomaly detection, and feature extraction. It also covers regularization techniques, sparse autoencoders, and transfer learning. Finally, it explores self-supervised learning methods, including context prediction, masked autoencoders, contrastive learning (SimCLR, SwAV), and multimodal models such as CLIP, which learn useful representations without requiring manually labelled data.
